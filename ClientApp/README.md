## Versioning / deploy check

The app shows its version at the bottom of the editor's **File** menu and in the Shell's **Settings** dialog, e.g.
`Frogmarks v0.01` with `built 2026-10-06 14:03 · Salsa 0.0.1 (dist 2026-10-05 00:53)` under it.

- **Bump before every deploy:** edit `APP_VERSION` in `src/app/app-version.ts` (`'0.01'` → `'0.02'` → …). That is the
  only place; `package.json` "version" is not used.
- **Build time + Salsa dist time** are stamped automatically: `npm run build` (= `scripts/build.mjs`, which is what
  `Frogmarks.csproj` runs on publish) runs `ng build` and then writes `<meta name="fm-build-time">`,
  `fm-salsa-version` and `fm-salsa-dist-time` into the built `index.html`. `ng serve` / `npm start` show "dev build".
- **To confirm a deploy** on the tablet: open File (or Shell → Settings) and check the version + build time. If it shows
  the old one, the browser has a cached `index.html`: reload.

## Installable app, offline, updates (PWA)

Production builds ship a web app manifest (`src/manifest.webmanifest`, icons in `src/assets/icons`, regenerated by
`node scripts/generate-pwa-icons.mjs`) and Angular's service worker (`ngsw-config.json`). Full notes:
`salsa/docs/ui/pwa.md`.

- **Deploy** = upload `dist/browser` (Cloudflare static assets). It contains `_headers` (from `src/_headers`), which
  makes `index.html`, `ngsw.json`, the worker scripts and the manifest revalidate on every load.
- **Always deploy the output of `npm run build`**, not plain `ng build`: `scripts/build.mjs` re-hashes `index.html` in
  `ngsw.json` after stamping it, and writes `APP_VERSION` into `ngsw.json` appData (the update prompt shows it).
- **After a deploy:** `node scripts/check-pwa-deploy.mjs https://<site>` checks the headers, that every file is
  served byte-identical to the build (no CDN HTML rewriting), and the SPA fallback.
- Running apps notice the deploy within 30 min (or when brought back to the foreground): the Shell shows
  "New version available: Reload", the editor an "Update ready" menubar button (saves first; never reloads by itself).
